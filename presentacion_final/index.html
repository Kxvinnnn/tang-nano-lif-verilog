Hardware-Accelerated Neuromorphic Architecture

Spiking Neural Network (SNN) on Sipeed Tang Nano 9K

1. Overview & Purpose

This system implements an event-driven Spiking Neural Network based on the biological Leaky Integrate-and-Fire (LIF) model, optimized for ultra-low-power embedded edge AI on the Gowin GW1NR-9C FPGA.

2. System Architecture

[Buttons S1/S2] ---> [Synchronizer & Debounce] ---> [BSRAM Synaptic Addressing] | [27 MHz Clock] ---> [50 Hz Prescaler Tick] ---> [LIF Neuron Core] <----+ | +-------------+-------------+ | | [LEDs 0..5 Outputs] [UART 115200 Transmitter]

3. Silicon Resource Utilization (GW1NR-9C)

  • Logic Cells (LUT4): 833 / 8,640 (9.64% utilization)
  • Flip-Flops (FFs): 207 / 6,480 (3.19% utilization)
  • Block RAM (BSRAM): 1 block (3.85% utilization for synaptic matrix)
  • Maximum Clock Frequency (F_max): > 100 MHz (operating comfortably at 27 MHz nominal)
  • Arithmetic DSPs: 0 / 20 (Zero DSP multipliers utilized)
