Arquitectura Neuromórfica Acelerada en FPGA

Red Neuronal Pulsante (SNN) sobre Sipeed Tang Nano 9K

1. Introducción y Propósito

Este sistema implementa una red neuronal pulsante basada en el modelo biológico Leaky Integrate-and-Fire (LIF) optimizada para hardware embebido de bajo consumo en la FPGA Gowin GW1NR-9C.

2. Arquitectura del Sistema

[Botones S1/S2] ---> [Sincronizador & Debounce] ---> [Direccionamiento BRAM] | [Reloj 27 MHz] ---> [Divisor Tick 1kHz] ---> [Neurona LIF] <---+ | +-------------+-------------+ | | [Salida LEDs 0..5] [Transmisor UART 115200]

3. Estimación de Recursos (GW1NR-9C)

  • LUTs: ~240 / 8,640 (2.7% de utilización)
  • Flip-Flops (FFs): ~185 / 6,480 (2.8% de utilización)
  • Bloques BRAM (BSRAM): 1 Bloque 36Kb inferido para pesos sinápticos.
  • Frecuencia Máxima ($F_{max}$): > 120 MHz (operando holgadamente a 27 MHz).

4. Guía Rápida de Comandos

make data # Genera pesos sinápticos hexadecimales make sim # Ejecuta simulación exhaustiva y genera ondas VCD make synth-open # Realiza Síntesis (Yosys) y Place & Route (NextPNR) make prog-flash # Programa la Flash permanente de la Tang Nano 9K
